# Dica diária — 2026-07-24

**Tema:** pronúncia alemã para PT-BR  
**Âncora:** Rammstein — “Feuer und Wasser”

## `eu` em alemão não é “e-u”

Em palavras como **Feuer**, o grupo `eu` normalmente soa perto de **“ói”** para ouvido brasileiro. O erro comum é ler letra por letra: “fe-u-er”. Isso deixa a palavra lenta e pouco alemã.

Treino curto:

- **Feuer** → pense em “fói-a”, com cuidado para não exagerar o `r` final.
- **heute** → “hói-te”, com `h` respirado no começo.
- **Deutsch** → “dóitch”, fechando no `tsch`.

A regra prática de hoje: quando vir `eu`, primeiro tente ouvir um ditongo só. Depois ajuste a palavra inteira.
