# Dica cultural / pronúncia — 2026-07-04

## Rammstein e o alemão de conto sombrio

“Mein Herz brennt” abre com clima de narrador, quase como se alguém estivesse contando uma história para crianças — só que com a luz apagada. Isso combina muito com uma tradição alemã de contos mais duros, tipo os Grimm: imagens simples, mas nada fofinhas.

Para pronúncia, a música ajuda porque Till Lindemann articula como ator de teatro. Não copie o exagero inteiro; copie a clareza:

- `z` vira `ts`: `Herz` não é “herrz”, é `herts`.
- `st` no começo vira `sht`: `Stimme` soa `shtí-me`.
- `ch` muda conforme a vogal: `Nacht` é mais fundo, `Licht` é mais fino.

Uma boa meta para iniciante: soar claro antes de soar rápido.
