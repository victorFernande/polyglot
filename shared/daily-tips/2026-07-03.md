# Dica cultural / pronúncia — 2026-07-03

## “Engel” mostra o lado solene do alemão, não só o lado pesado

Rammstein parece uma porta de entrada óbvia para consoantes fortes, mas **“Engel”** também ajuda por outro motivo: ela tem uma solenidade quase de hino. Isso deixa as vogais mais expostas. Quando a voz segura uma palavra, fica mais fácil perceber se você está confundindo `ie` com `ei` ou colocando som demais onde não precisa.

Para iniciante, isso vale ouro. Música lenta ou marcada não serve só para “entender a letra”; serve para enxergar a boca trabalhando em câmera lenta.

### Dica prática

Hoje, separe estes dois reflexos:

- `ie` → som de **i** longo: **fliegen**, **Lied**, **lieben**.
- `ei` → som de **ai**: **allein**, **ein**, **mein**.

Não tente decorar uma tabela gigante. Pegue um par por dia. O ouvido alemão fica menos assustador quando você vence um contraste pequeno de cada vez.
