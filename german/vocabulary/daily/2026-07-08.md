# Vocabulário diário — 2026-07-08

## Alemão FASE 1 — Rammstein: “Keine Lust”

Hoje a âncora é “Keine Lust”. A faixa é perfeita para ouvir ditongos (`ei`, `au`), `k` bem seco e aquele jeito alemão de fechar palavra sem colocar uma vogal brasileira no final.

| Palavra | Como ler de leve | Sentido | Onde prestar atenção |
|---|---|---|---|
| keine | kái-ne | nenhuma / não... algum | `ei` soa `ai`; o `k` entra seco, sem “quei”. |
| die Lust | lust | vontade / desejo | `u` fechado e `st` final bem curto, sem vogal extra. |
| ich | ikh | eu | `ch` depois de `i` é fino, soprado, não é `x` carioca pesado. |
| habe | há-be | tenho | O `h` respira; `b` fica limpo, sem virar `v`. |
| mehr | mêa | mais | O `r` final quase some; segure a vogal antes dele. |
| schwer | shvêa | pesado / difícil | `schw` começa como `shv`; boa palavra para treinar boca redonda. |
| groß | grôss | grande | `ß` soa `ss`; o `o` é longo e firme. |
| bewegen | be-vê-gen | mover / mexer | `w` soa `v`; `g` é duro, sem som de “j”. |

### Micro-contexto
“Keine Lust” tem uma preguiça teatral, quase grotesca. Para a FASE 1, isso ajuda: o ritmo é arrastado o suficiente para você caçar sons sem precisar entender cada frase de primeira.

### Treino de 3 minutos
1. Repita: `keine, schwer, bewegen` — ouvindo `ei = ai` e `w = v`.
2. Faça finais secos: `Lust, groß, ich`.
3. Feche com: `Ich habe keine Lust.` — devagar, com o `ch` fino e sem cantar.
