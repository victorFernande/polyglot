# Vocabulário diário — 2026-07-06

## Alemão FASE 1 — Rammstein: “Radio”

Hoje a âncora é “Radio”: boa para treinar `r`, sons de `sch/sp` e palavras com clima de transmissão clandestina. A música fala de desejo de ouvir o mundo por uma fresta — perfeito para estudar som antes de sair traduzindo tudo.

| Palavra | Como ler de leve | Sentido | Onde prestar atenção |
|---|---|---|---|
| die Frequenz | fre-kuênts | frequência | `qu` soa `kv`; `z` final puxa para `ts`. |
| die Antenne | an-tê-ne | antena | Dois `n`, mas sem drama; mantenha as sílabas limpas. |
| das Rauschen | ráu-shen | chiado / ruído | `sch` vira `sh`; `au` soa como “au” curto. |
| empfangen | emp-fan-gen | receber / captar | Palavra de rádio mesmo; `ng` fecha compacto no fim. |
| heimlich | háim-likh | secreto / às escondidas | `ei = ai`; `ch` depois de `i` é mais fino. |
| verboten | fer-bô-ten | proibido | `v` inicial soa `f`; palavra útil para clima de censura. |
| die Sehnsucht | zên-zukht | saudade / anseio | `s` inicial soa `z`; `ch` depois de `u` fica mais áspero. |
| der Sender | zên-der | emissor / estação | `s` inicial vira `z`; `-er` final pode ficar bem leve. |

### Micro-contexto
“Radio” tem clima de antena clandestina: alguém tentando captar música, notícia e vida do lado de fora. Para a FASE 1, use isso como treino de escuta: som primeiro, explicação depois.

### Treino de 3 minutos
1. Repita em pares: `Frequenz / Antenne`, `Rauschen / Sender`, `heimlich / verboten`.
2. Faça o contraste: `sch` cheio em `Rauschen`, `ch` fino em `heimlich`, `ch` áspero em `Sehnsucht`.
3. Feche com: `Ich empfange einen Sender.` — frase só para sentir ritmo e consoantes.
